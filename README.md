# IPL 2008-2026 Analytics Dashboard

A Platform for IPL fans — compare teams, dig into player performance, browse match history, and compare players based on point system, all in one dashboard.

## What it does

Built for anyone who loves comparing IPL teams and players — Season-by-season stats, match-level breakdowns, Team and player level Comparison and fantasy scoring into a single interactive dashboard.

## Features

- **Season Overview** — league-wide trends and stats across seasons
- **Match Profile** — detailed breakdown of individual matches
- **Team Profile** — compare teams head-to-head, win/loss records, performance trends
- **Player Profile** — track individual player stats and form over time
- **Phase Analysis** — powerplay / middle-overs / death-overs performance breakdown
- **Fantasy Points** — fantasy scoring system built on ball-by-ball data

## Tech Stack

Python, Pandas, Streamlit, Plotly, Numpy

## Run it locally

```bash
git clone https://github.com/VishalPathak01/<repo-name>.git
cd <repo-name>
pip install -r requirements.txt
streamlit run app.py
```
